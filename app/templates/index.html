How to update

Linux / macOS (installed with ybx.sh)

If you installed with the one-liner, run the upgrade command:

ybx.sh upgrade

No ybx.sh command? Run the installer again (it upgrades in place):

curl -fsSL https://raw.githubusercontent.com/tabebqena/yolo-box-editor/main/ybx.sh | bash -s -- upgrade

Windows / manual install (git clone + pip)

From your yolo-box-editor folder, pull the new code and reinstall dependencies:

git pull
python -m pip install -r app/requirements.txt

Windows PowerShell (using the app's virtual environment):

git pull
.\.venv\Scripts\python.exe -m pip install -r app\requirements.txt

Your actions/, hooks/, filters/, scripts/ and shortcuts.txt are never touched by an update. Restart the app afterwards.
