# yolo-box-editor keyboard shortcuts.
# Syntax (one line per action):  ACTION_NAME  <SHORTCUT>  label shown in the UI
#
# SHORTCUT: zero or more modifiers joined with '+', then the main key, wrapped
# in < > to separate it from the label. Supported modifiers: Ctrl Alt Shift Meta
# (order doesn't matter). Keys: letters (A..Z), digits (0..9), or e.key names
# like Escape, Delete, Backspace, ArrowLeft, ArrowRight, Space.
#
# The label after the closing '>' is free text displayed in the shortcuts bar.
# Lines starting with # are ignored.
#
# ACTION_NAME must be one of:
#   - a built-in app action (app_*), listed below, or
#   - an action you defined in actions.yaml.
# Anything else is reported as an error banner on the page (dismissible).
#
# Built-in app actions — edit the bindings or labels freely:
app_help     <F1>            open help / tutorials
app_prev     <ArrowLeft>     prev image
app_next     <ArrowRight>    next image
app_del      <Delete>        delete box
app_drop     <Escape>        drop new box / deselect
app_undo     <Z>             undo
app_redo     <Y>             redo
app_save     <S>             save labels
app_ch_box   </>             change box class
app_sel_box  <Shift>         select next box
app_sel_points <Tab>      toggle active input
app_escape    <Escape>    Ignore
app_show_hide <.>         hide/show boxes
app_box_details <,>       box details on/off (outlines only)
app_fix_box  <F>          fix/unfix selected box
# app_force_draw is a held modifier, not a key: hold it and drag to always
# draw a new box (even on top of / inside an existing one). Use Ctrl or Meta on
# Linux (Alt+drag is grabbed by many window managers); Shift stays reserved for
# selecting. Put personal remaps in your own shortcuts.txt (in the user folder).
app_force_draw <Ctrl>     hold + drag = new box
#
# An action from actions.yaml can also be bound here, e.g.:
# Remove       <Ctrl+Shift+R>   Delete the current image
#
# App updates replace only the app/ folder. Keep your personal remaps in your
# own shortcuts.txt (in the user folder, next to app/): it is read after this
# file and wins on a name clash. The app creates it when missing.
