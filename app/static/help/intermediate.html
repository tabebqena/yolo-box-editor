Intermediate — shape the workspace and speed up editing

Once the basics feel natural, tune the UI to your taste and edit boxes without leaving the keyboard.

Arrange the UI (Settings → Layout)

  • Panel side: put the control panel on the left or right.
  • Widgets: Tags, Boxes, Actions, Navigation and Save/Undo can each be shown or hidden and docked to the left panel, right panel, bottom panel, or a floating window — or reset to their default spot. A floating window is dragged by its title bar and docked with the L/T/R/B buttons.
  • Resize the side, dock and bottom panels by dragging their divider. Panels only appear while they hold a visible widget.

The layout is saved and shared with the server, so a fresh browser starts with the same arrangement.

The Boxes list

Every box of the current image has a row with its class dropdown and cx cy w h number fields. Click a row to select that box (its controls become editable and the others grey out). Changing a value moves or resizes the box live; the canvas highlights what you are editing: cx/cy show an orange dot at the centre, w/h show orange dashes on the matching edges.

Edit a whole row with the keyboard

  1. Select a box (click it or press Shift).
  2. Press Tab. Focus jumps into its row and cycles: class → cx → cy → w → h → class …
  3. Press Esc to leave the row and clear the highlight.

Protect a finished box: fix it

Press F (or click the F button in its row) to fix a box. A fixed box has a dashed grey outline and no handles: it ignores dragging and resizing but can still be selected and deleted, and it is click-through — you can still click the boxes inside it to select them. Handy when you need to draw next to — or inside — a box you are happy with. Fixing is transient and is never saved.

Declutter the canvas

  • . — hide / show all boxes on the image (hidden boxes ignore the mouse, so you can see the photo).
  • , — box details on / off: hide the handles, labels and the × / / buttons, leaving plain outlines.
  • I — isolate: show only the selected box.

The same switches live on the slim canvas toolbar above the image (+, ▣, Details, Isolate, Boxes, Draw), so mouse-only users can reach them too.

Edit with either device alone

Every core step works with the keyboard only or the mouse only:

  • Create a box: press N (keyboard) or click + on the canvas toolbar (mouse).
  • Move a box: press Alt+arrow (keyboard) or drag it (mouse). A held keyboard move collapses into one undo step.
  • Resize: drag a handle (mouse) or Ctrl+arrow (keyboard).
  • Select: click (mouse) or Shift/Ctrl+A (keyboard).
  • Draw on top: hold the modifier (keyboard) or toggle Draw on the toolbar (mouse).

Tags (extension)

Tags label a whole image (for example night or hard), not a box. They ship as the Tags extension package, enabled by default — toggle it under Settings → Extensions. The available tags come from tags.yaml beside data.yaml.

  • Click a badge to toggle it on/off for the current image — it is saved immediately.
  • Click +, type a name and press Enter to add a new tag (also written to tags.yaml).
  • Alt+1 … Alt+9 toggles the numbered tags.

Filters — work a subset

Settings → Filters → Active chain stacks up to 8 filters that run top to bottom and narrow the image list (for example “contains class” or “has tag”). Use + Add filter, pick each filter, fill its arguments, then Apply. The chain is remembered per dataset.

Navigate quickly

  • Type a number in the image counter and press Enter to jump.
  • The Split picker switches between train / val / test, or shows all splits together.
  • Your last image is remembered per split, so switching back returns you to it.

Save behaviour and read-only

  • Auto-save (Settings → General) saves after each edit, so navigating never asks you to save.
  • Read-only (Settings → General, or --readonly) blocks drawing, editing and saving so you can browse safely.
