Beginner — your first boxes

A guided first run: start the app, find your way around the screen, and draw, move, resize and delete boxes. No prior labelling experience needed.

1. Start the app

If you installed with the one-liner, the ybe command is ready:

ybe start --data /path/to/dataset/data.yaml

From a clone, run it directly:

python app/app.py --data /path/to/dataset/data.yaml

Then open http://127.0.0.1:5000 in your browser. No --data? The app reopens the dataset you used last, or shows the Load a dataset box — paste the path to your data.yaml and press Load.

2. Find your way around the screen

  • Control panel (left or right): the app name with the ? help, ⚙ settings, bell and Panel buttons; the dataset name; the Split picker; your Actions; and the Boxes list for the current image.
  • Canvas (middle): the picture you label. This is where you draw.
  • Bottom bar: tags (if enabled), Prev / image counter / Next, and Undo / Redo / Save.
  • ⚙ Settings: dataset, view/layout, filters and shortcuts.

Lost something? Every panel can be moved. See the Intermediate tab for the layout options.

3. Draw a box

  1. Drag on the image from one corner of the object to the opposite corner. A rectangle follows the mouse.
  2. On release, a class list appears — click the object's class (or press its number). A coloured box with a label appears.

The new box is selected: yellow on the canvas, with its row active in the Boxes list.

To draw inside or on top of an existing box, hold the force-draw modifier (default Ctrl) and drag. A plain drag inside a box moves that box instead.

4. Move and resize a box

  • Move: click inside the selected box and drag.
  • Resize: drag one of the eight square handles (corners and edge midpoints).
  • Type exact values: click the cx, cy, w or h field in the box's row and type. Coordinates are fractions of the image (0–1), so 0.5 is the centre.

5. Delete a box

Select it, then press Delete or Backspace — or click the × in its row in the Boxes list. Deleting several selected boxes asks you to confirm first.

6. Select a box

  • Click it on the canvas, or click its row in the Boxes list.
  • Hold Ctrl and click to add more boxes (Ctrl+click again to remove one). Drag any selected box to move them together, or press Delete to remove them all.
  • Press Ctrl+A to select every box.
  • With a box selected, Ctrl+←/→/↑/↓ widen a border; add Shift to narrow it.
  • Press Shift to jump to the next box.
  • Press Esc to deselect.
  • If a text field has focus and shortcuts stop working, press Space to focus the canvas.

7. Change a box's class

With the box selected, press / or click the / on the box, then pick the class — use ↑/↓ and Enter (or a number key) to choose from the list.

8. Save, undo and move between images

  • S or Save writes the current image's boxes to labels/<split>/<image>.txt.
  • Z / Y undo / redo edits to the current image.
  • ← / → or Prev / Next change image. Save first — unsaved boxes live only in the session.
